# Rainbow Finder

PWA-приложение для поиска радуги с компасом, анализом погоды и научным расчётом вероятности.

## Возможности

- Красивый интерактивный компас с направлением к радуге
- Научный расчёт вероятности радуги на основе:
  - Положения Солнца (азимут, высота над горизонтом)
  - Текущих метеоусловий (осадки, облачность, влажность)
  - Прогноза погоды (ожидаемый дождь)
- Реальные данные погоды по геолокации (OpenWeatherMap API)
- PWA — устанавливается на Android и iOS
- Работает офлайн (кэширование через Service Worker)
- Адаптивный дизайн для мобильных устройств

## Научная база

Радуга образуется при преломлении солнечного света в каплях воды. Ключевые условия:

1. **Солнце за спиной** — центр радуги находится в антисолнечной точке
2. **Угол 42°** — первичная радуга видна под углом 42° от антисолнечной точки
3. **Солнце ниже 42°** — иначе радуга будет ниже горизонта
4. **Капли воды** — дождь, морось или туман перед наблюдателем

## Запуск

```bash
npm install
npm start
```

Откройте http://localhost:3000

## Переменные окружения

| Переменная | Описание |
|---|---|
| `OPENWEATHER_API_KEY` | API ключ OpenWeatherMap |
| `PORT` | Порт сервера (по умолчанию 3000) |

## Технологии

- Node.js + Express (сервер)
- Vanilla JS с ES-модулями (клиент)
- Canvas API (рендеринг компаса)
- Geolocation API + DeviceOrientation API
- OpenWeatherMap API (погода)
- Service Worker (офлайн-кэширование)
